Need help using Mail Pawns ?

Mail Pawns helps you check if an email is safe or a possible threat — by analyzing both the text and any links inside the message.

How to use it :

  1. Paste an email into the input box — it can include text, links, or both.
  2. Click the Scan button to start the scaning.
  3. The system will analyze the content and links using AI models, and give you a result:
    • Safe → No threats found .
    • Malicious → Be careful! The email might be harmful .
  4. If it’s malicious, you can either move it to the Junck folder or simply Reset and paste another email to check.
