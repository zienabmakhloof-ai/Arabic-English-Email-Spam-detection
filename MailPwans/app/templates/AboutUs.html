This project was independently developed as a personal initiative focused on protecting users from malicious emails using artificial intelligence — with a special emphasis on the Arabic language.

📧 About the Project

Mail Pawns is an AI-powered email threat detection system designed to protect users from phishing, spam, and malicious links. It supports both Arabic and English content analysis using fine-tuned BERT-based models, with a dedicated focus on Arabic — a language often underserved by mainstream cybersecurity tools.

The system analyzes email text and embedded URLs to classify threats with high accuracy, making it accessible even for non-technical users.

⚙️ Key Features

  • 🔗   Malicious URL detection using a Logistic Regression model
  • 🌐   Bilingual email text analysis (Arabic & English)
  • 🤖   BERT-based models for high-accuracy classification
  • 🛡️   Designed to be simple and accessible for everyday users
